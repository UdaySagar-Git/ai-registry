Set up a project (creates .registry/manifest.yml)

Usage: aireg init [--for <harness>,...] [--force]
       aireg init --registry <registry> [--as <name>] [--watch] [options]

Options:
      --for <harness>                      The harnesses to install into, comma-separated, or * for all of them
      --force                              Replace an existing manifest, keeping the registries it declares
      --registry <registry>                The registry to set the project up from
      --as <name>                          The name to save the registry under
      --publish-to <registry>/<namespace>  Where aireg publish sends work when --to is not given
      --watch                              Keep the project in sync with the registry in the background
      --import <harness>                   Import what these harness folders hold: agents, claude, codex or all
      --adapter <id>                       The adapter that reads the registry, when aireg cannot tell
      --token-stdin                        Read the registry's token from standard input

Examples:
  $ aireg init --for claude,cursor                                       a project for Claude Code and Cursor
  $ aireg init --registry github.com/acme/ai-registry --as acme --watch  set up from a team registry, kept in sync

Learn more:
  Run `aireg --help` for the global options (--json, --verbose, -q, --color, --no-color, --log-level, -y).
  Docs: https://atlanai.github.io/ai-registry/reference/init/
